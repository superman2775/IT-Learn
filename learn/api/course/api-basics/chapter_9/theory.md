# Documentation and Testing Tools

Good APIs come with clear documentation.
It tells you:
- Base URL
- Endpoints
- Required fields
- Example responses

A common format is OpenAPI (Swagger).
It can generate a test page.

Useful tools:
- `curl` for quick requests
- Postman for testing and saving requests

Example with curl:

```bash
curl https://api.example.com/users/42
```

Clear docs help you use an API faster.
